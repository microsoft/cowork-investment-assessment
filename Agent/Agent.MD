# Agent – Pre-built Copilot Cowork Investment Assessment Agent

## Overview

This is a pre-built declarative agent packaged as a zip file. An admin can download it and make it available to all users in the organisation.

## Download & Deployment Instructions

> **Note:** The zip file and deployment instructions will be provided here once the agent package is available.

### Prerequisites

- Microsoft 365 admin access
- Microsoft 365 Copilot licences assigned to target users
- Access to the Microsoft 365 Admin Centre or Teams Admin Centre

### Steps

1. **Download** the agent zip file from the link provided below.
2. **Navigate** to the Microsoft 365 Admin Centre > Settings > Integrated Apps, or use the Teams Admin Centre > Manage Apps.
3. **Upload** the zip file as a custom app.
4. **Assign** the agent to the appropriate users or groups.
5. **Verify** the agent appears in users' Copilot experience.

### What the Agent Does

This agent performs a Copilot Cowork Investment Assessment — it identifies workflows suitable for Copilot Cowork automation, assesses complexity, calculates credit consumption and ROI, and provides executive-level recommendations. See [Prompt.MD](../Prompt/Prompt.MD) for the full assessment methodology.
